☕ Coffee Sales Analysis Dashboard — Power BI
📊 Project Overview

This project is an interactive Coffee Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard transforms coffee sales data into meaningful visual insights, helping analyze sales performance, product performance, customer trends, and overall business performance.

The project demonstrates the use of data cleaning, data transformation, DAX calculations, KPIs, and interactive data visualization in Power BI.

🎯 Project Objectives
Analyze overall coffee sales performance
Identify top-performing coffee products
Understand sales trends over time
Compare product categories
Analyze customer purchasing patterns
Track key business KPIs
Create an interactive and user-friendly dashboard
Convert raw sales data into actionable business insights

🔄 Data Preparation

The data was processed using Power Query before creating the dashboard.

The main steps included:

Importing the coffee sales dataset
Cleaning the raw data
Handling missing or inconsistent values
Formatting columns and data types
Creating calculated columns where required
Loading the cleaned data into Power BI
Creating DAX measures
Designing the interactive dashboard
🧮 DAX

DAX (Data Analysis Expressions) was used to create calculated measures and support the dashboard's analytical requirements.

Examples of measures include:

Total Sales
Total Quantity
Total Orders
Average Sales
Sales Growth

These measures are used across the dashboard to dynamically update the displayed KPIs and visualizations.
